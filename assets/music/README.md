# Optional: your own reel music

Drop royalty-free tracks here (`.mp3`, `.m4a`, `.wav`, `.ogg`) and commit them.
With `MUSIC=auto` (default) each reel picks one of these files; if the folder has no audio files,
the agent generates an original track instead (`src/music.ts`).

Only use music you are licensed to post on Facebook (e.g. tracks whose licence allows social-media use
without attribution). Copyrighted songs can get the reel muted or blocked.
